# 🌿 Edenia

**Feel at home in your life.**

Edenia is a private, gentle space to plan, track habits, take notes and reflect, all in one place. There are no rigid hourly schedules and no guilt for missed days. It is meant to feel like stepping into your own garden: calm, unhurried and yours.

> *Welcome back. Your garden waited for you.*

## Why Edenia?

The name comes from the Garden of Eden: a first home, a private garden where nothing is rushed and nothing is hidden. The *-ia* ending makes it a place, a small world of your own.

Edenia is also my full-stack learning project. I am building it in stages, from plain HTML, CSS and JavaScript up to React, Node, Express, a database, authentication and deployment.

## Status

🚧 **Work in progress.** Currently building **version 1** (plain HTML, CSS and JavaScript, with data saved in the browser).

## MVP (first milestone)

- **Habits with streaks:** add habits, tick them off each day, and see how many days in a row you have done them.
- **Simple notes:** write quick notes and keep them in a list.
- **In-app reminders:** set a reminder and get a pop-up when the time comes.

See [docs/mvp-plan.md](docs/mvp-plan.md) for the task breakdown. Progress is tracked in the [Issues](../../issues) tab.

## Planned features

- Goals with progress tracking and reviews
- Journal with text, photos, voice notes and video
- Library for books, articles, podcasts and more
- Planner (daily to yearly) without hourly time slots
- Writing workspace for drafts
- Vision board
- Challenges and a focus timer
- Accounts and login, calendar sync, and optional AI help

The full plan is in [docs/project-vision.md](docs/project-vision.md).

## Getting started

Version 1 has no build step.

1. Clone the repo:
   ```bash
   git clone https://github.com/Samcodex-405/edenia.git
   ```
2. Open `v1/index.html` in your browser.
